# Нативные кампании — пакет скилов v0.1

Четыре самостоятельных скила для русскоязычных нативных статей. Их можно
использовать в агентном клиенте или загружать в контекст собственной модели.
Инструкции не зависят от конкретного поставщика LLM. Доступ к файлам, поиску
и Wordstat определяется средой выполнения; сам пакет эти инструменты не подключает.

## Состав

| Скил | Когда использовать | Результат |
|---|---|---|
| `campaign-context` | Есть материалы клиента, нужен рабочий бриф | `brief.md`: цель, аудитория, факты с источниками, гипотезы, ограничения |
| `campaign-plan` | Нужно выбрать темы и подготовить задания авторам | `plan.md`: темы, польза, тезисы, доказательства, интеграция продукта, CTA |
| `native-article` | Есть бриф и задание на одну статью | `articles/t1.md`: текст, CTA и отдельные служебные сведения |
| `article-review` | Есть статья, нужен вердикт или проверка доработки | `reviews/t1.md`: замечания с важностью и критериями исправления |

Каждый скил содержит все необходимые инструкции и работает отдельно.
Другие скилы можно использовать по имени, если они установлены; отсутствующий
скил не нужно имитировать или считать обязательной зависимостью.

## Пробный запуск

В клиенте с поддержкой скилов сделайте четыре папки из `skills/` доступными
для обнаружения. Для клиентов, сканирующих проектную `.agents/skills/`, можно
скопировать туда эти папки. Путь и способ подключения зависят от клиента.
Пакет хранится здесь как исходный артефакт; глобальная установка не выполнена.

Без автоматического обнаружения передайте модели нужный `SKILL.md` целиком
вместе с заданием и входными материалами. Это не добавляет модели файловые
инструменты, поиск или гарантированное соблюдение инструкций.

Пример полного задания после подключения скилов:

```text
Используй campaign-context, campaign-plan, native-article и article-review.
Подготовь две нативные статьи по приложенному брифу и материалам продукта.
Сначала нормализуй контекст, затем выбери темы и составь задания авторам.
Напиши статьи и проверь каждую. Доработай их один раз по замечаниям.
Верни текст и итоговый вердикт для каждой статьи.
Папка кампании: campaigns/sever-demo. Без внешнего поиска и платных инструментов.
```

Имена в примере являются запросом агенту; некоторые клиенты используют
`$campaign-context`, `/campaign-context` или собственный механизм выбора.

Пример для одного этапа:

```text
Используй article-review. Проверь articles/t1.md относительно brief.md
и задания T1 из plan.md. Верни конкретные замечания и вердикт.
```

Если файловые инструменты отсутствуют, каждый результат возвращается в чате
с указанием предполагаемого имени файла. Нельзя заявлять, что файл сохранён.

## Передача контекста

Используйте отдельную папку для каждой кампании. Входы выбираются явно
из задания; скилы не ищут досье других клиентов по всему компьютеру.
Факты получают идентификаторы F1, F2 и ссылки на источники S1, S2.
Гипотезы выделяются отдельно. План ссылается на версию брифа;
статья — на версии брифа и плана; ревью — на версию статьи.

Неподтверждённое свойство продукта не становится фактом после повторения
в плане, статье или ревью. Недостаток данных указывается явно.
Служебный реестр утверждений хранится отдельно от публикуемого текста.

## Проверка пакета

Сценарии и критерии: [evals/cases.md](evals/cases.md).
Фактические результаты: [evals/results.md](evals/results.md).

Это небольшой пробный пакет. Структурная проверка и отдельные поведенческие
прогоны не подтверждают рост конверсии и не гарантируют одинаковое поведение
всех моделей. Для продуктового решения сравните версии на реальных брифах:
точность утверждений, соответствие задаче, полезность, стоимость и ручные правки.

## Происхождение

Инструкции написаны для этого проекта. При проектировании учитывались
идеи общего маркетингового контекста и проверок по отдельным критериям из
[marketingskills](https://github.com/coreyhaines31/marketingskills), а формат
ориентирован на [Agent Skills](https://agentskills.io/home).
Полные тексты сторонних скилов и их статистические обещания не включены.

Интеграция с Go backend, изменение интерфейса и подключение MCP
не входят в эту версию пакета.
